# Paycom Connector — Ideal Onboarding

## Administrator Setup Steps
1. Log in to Paycom Client Portal at `paycomonline.net`.
2. Locate your Client Code in the header or company profile settings.
3. Navigate to System Settings > Integrations / API Access and generate an API Token.
4. In Imperal, open the Paycom sidebar, enter Connection Label, API Token, and Client Code.
5. Click **Connect Paycom**. The connector validates the token against the verification endpoint before saving.
